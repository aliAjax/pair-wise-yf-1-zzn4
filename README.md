# 矿井通风测点复核台

React + Vite 单页应用：矿井通风测点登记、阈值复核、巡检路线占用与整次提交校验。数据只存浏览器 localStorage，刷新后保留。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
npm run preview  # 预览构建产物
```

## 业务规则

- 预置 3 条巷道（各含一条巡检路线及容量）和 4 个测点。
- 登记项：风速、甲烷、氧气、温度、测量人、测量时间。
- 风速 < 1 m/s 或 甲烷 > 1% → 测点进入「待复核」，并移出巡检路线（不占用路线容量）。
- 整次巡检提交：任一测点待复核，或任一路线容量已满（占用 ≥ 容量）→ 整次拒绝，测点、路线、原始记录全部保持不变（仅追加一条拒绝日志）。
- 复核放行后：测点卡片、路线表、统计面板由同一状态派生，自动同步。
- 路线容量可在路线表中调整，便于演示「容量已满」的拒绝分支。

## 结构

- `src/domain.js` — 阈值判定、路线占用、整次提交校验、reducer、预置数据、localStorage 读写（纯函数，可独立测试）
- `src/App.jsx` — 页面组合与交互
- `src/components/` — 统计条、测点卡片、登记表单、路线表、提交面板、原始记录表
